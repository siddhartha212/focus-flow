# ⚡ FocusFlow Hub

An all-in-one personal productivity suite, time-blocker, habit tracker, and notes app built with React, TypeScript, Tailwind CSS, and local-first storage.

## ✨ Features
- 📅 **Today Time-Blocker**: Hourly timeline (6 AM - 11 PM), focus timer, unscheduled tray.
- 📆 **Dual Calendar Engine**: Exact Bikram Sambat (BS) date converter synchronized with Gregorian dates.
- 📸 **Multi-Media Quick Capture**: Base64 photo capture, video upload, and live voice recording notes.
- 📝 **Notes Workspace**: Searchable, categorised, pin-to-top, and color-coded notes.
- ⚡ **Habits & Heatmaps**: Streak tracking engine with interactive 90-day heatmap matrix.
- 🌐 **Bilingual (English & नेपाली)**: Instant language switching across all modules.
- 📱 **Mobile APK Ready**: GitHub Actions cloud pipeline to build Android APKs automatically.
